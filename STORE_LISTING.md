# Obsidian Community listing

## Name

Yaps

## Description

Dictate into notes and search your private local Markdown vault with Yaps.

## Reviewer summary

Yaps for Obsidian is a desktop-only companion for the separately installed Yaps app. It focuses the current Markdown editor for global Yaps dictation, displays the user's configured shortcut, searches the active local vault, captures selected text as a new local note, and opens a Yaps-compatible daily note.

The plugin has no analytics, remote API client, microphone capture, embedded model, or bring-your-own-key flow. It invokes the installed Yaps CLI without a shell and supplies the active vault root on every operation. Users who do not have Yaps installed receive an explanatory modal with an explicit, user-clicked link to `https://yaps.ai/download`.

## Distribution copy

### Short

Your voice, directly in Obsidian—cleaned up by Yaps, with private local-vault search built in.

### Long

Turn rough speech into clean writing without leaving your note. Yaps for Obsidian prepares the live editor for your existing Yaps dictation shortcut, keeps the shortcut visible, searches your local Markdown memory, captures a selection into a new note, and opens today's daily note. The plugin stays local and requires the Yaps desktop app for dictation and account access.

### Primary call to action

Install the Community plugin, then download and sign in to Yaps at `https://yaps.ai/download`.
